# 梗果忍者

竖屏网页切割小游戏。用手指或鼠标按住划动，躲开炸弹。

## 发布到 GitHub Pages

1. 创建一个公开仓库，例如 `geng-guo-ninja`。免费个人账号使用公开仓库即可开启 Pages。
2. 解压发布包，把其中的文件和 `media` 文件夹上传到仓库根目录。不要只上传 ZIP；根目录必须能看到 `index.html`。
3. 进入仓库的 **Settings → Pages**。
4. 在 **Source** 选择 **Deploy from a branch**，选择 **main** 和 **/(root)**，保存。
5. 等待部署完成，使用 Pages 页面显示的游戏网址。通常形如 `https://你的账号.github.io/仓库名/`，实际地址以 GitHub 显示为准。

不需要安装依赖或运行构建。所有图片、音频与脚本都随游戏一起发布，路径兼容仓库名子目录。

## 试玩说明

- 点击“开始切”后启用声音。
- 普通一局 30 秒；冰冻、加速和刀光技能按游戏内规则生效。
- 昵称、成绩、人物次数、成就和刀光解锁保存在当前浏览器中；更换网址或浏览器后不会自动迁移。
- 此版本没有多人账号或在线排行榜。
- GitHub Pages 无法保证中国大陆所有网络、QQ或微信内置浏览器都能访问；发布后应让试玩者在自己的网络下测试。

## 素材说明

包含已有游戏所使用的人物贴图、角色音效与原创界面。部分素材来自用户提供的图片和视频，以及已有公开参考；本包不附带原始视频。素材权利归各自权利人，不附加开放授权。

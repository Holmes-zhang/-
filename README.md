# 梗果忍者

竖屏网页切割小游戏。按住划动，躲开炸弹。

## 更新现有 GitHub 仓库

1. 解压 ZIP，打开 `GitHub-upload` 文件夹。
2. 仓库页面点击 **Add file → Upload files → choose your files**。
3. 在文件选择窗口进入这个文件夹，按 **Ctrl+A** 全选文件，再打开。所有文件直接放在仓库根目录，不需要创建或上传文件夹。
4. 等所有文件上传结束，点击 **Commit changes**。同名的 `index.html`、`assets.js` 等文件会更新。
5. 等 Pages 自动部署完成，刷新游戏网页。

每个 PNG、MP3、SVG 都是游戏素材，请全部上传。本包的文件在同一层，不能混用旧版指向 `media` 文件夹的 `assets.js`。

开始按钮启用声音。30 秒一局，成绩、成就和刀光解锁保存在当前浏览器中。国内网络和 QQ、微信内置浏览器的访问情况需要试玩者实际测试。

素材为已有游戏素材，权利归各自权利人；本包不附带原始视频，也不附加开放授权。
